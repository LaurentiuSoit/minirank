# MiniRank

A keyword position tracker for a single website. All ranking data is simulated locally — no search engines or external APIs involved. Positions are numbers 1–100 where **lower is better** (rank 1 is the top result, 100 is the worst).

This is a single-user app — there is no login. The website being tracked is configured in code (`src/db.php`).

## What it does

- **Keyword list** — see every tracked keyword, its current position, a 7-day trend indicator (improved / declined / stable), and search by phrase.
- **Add / Edit / Delete** keywords through simple HTML forms.
- **Refresh positions** — generates a new simulated position for today for every keyword via AJAX, without a page reload.
- **Keyword detail** — per-keyword page with the full position history as a table.

## Tech stack

- **PHP 8**, plain PHP with PDO — no framework.
- **SQLite** via `PDO_SQLite`, stored as `data/minirank.sqlite` (git-ignored, regenerated by the seed script).
- **Vanilla JS** for the AJAX refresh, hand-written CSS for layout (mobile-responsive).

## Requirements

- PHP 8.1+
- The `pdo_sqlite` PHP extension (included in most PHP installations).

## Setup

```bash
# 1. Clone and enter the directory
git clone <repo-url> minirank
cd minirank

# 2. Seed the database (creates schema + 30 days of demo data)
php seed.php

# 3. Start the built-in server
php -S localhost:8000 -t public public/router.php

# 4. Open in your browser
open http://localhost:8000
```

That's it — the app is running. To start fresh at any time, re-run `php seed.php` (it deletes and recreates the database).

## Usage

| Action | How |
|---|---|
| Add a keyword | Click **Add keyword**, enter a phrase, submit. |
| Edit a keyword | Click **Edit** on a keyword row or on the detail page. |
| Delete a keyword | Click **Delete** (positions are cascade-deleted automatically). |
| Search | Type in the search box on the list page. |
| Refresh positions | Click **Refresh positions** on the list page — updates live via AJAX. |
| View history | Click a keyword's phrase to go to its detail page. |

### Trend indicator

The 7-day trend compares today's position to the position from 7 days ago:

- **improved** — position went down (e.g. 37 → 12)
- **declined** — position went up (e.g. 12 → 37)
- **stable** — no change

## Security

- Every database query uses a **prepared statement** with bound parameters — no SQL is ever built by string concatenation.
- Every value printed into HTML is passed through `htmlspecialchars()` (via the `escape()` helper).
- `$_GET` and `$_POST` inputs are validated and cast before use: IDs are integers, search terms and keyword phrases are strings with a length cap.
- No secrets are committed. The only configuration is `SITE_URL` (a plain website URL used as the tracked domain), and the database file is git-ignored.

## Database schema

```sql
keywords (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    phrase     TEXT    NOT NULL,            -- the search keyword
    website    TEXT    NOT NULL,            -- the tracked site (constant)
    created_at TEXT    NOT NULL DEFAULT (datetime('now'))
)

positions (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    keyword_id  INTEGER NOT NULL,
    position    INTEGER NOT NULL CHECK (position >= 1 AND position <= 100),
    recorded_at TEXT    NOT NULL,            -- date key: YYYY-MM-DD
    UNIQUE (keyword_id, recorded_at),
    FOREIGN KEY (keyword_id) REFERENCES keywords (id) ON DELETE CASCADE
)
```

The seed script generates 10 keywords with 30 days of random-walk positions starting at a random base of 20–80. The refresh endpoint walks each position by ±3 per day, clamped to 1–100.

## Resetting

```bash
php seed.php          # wipes data/ and regenerates the database
```
