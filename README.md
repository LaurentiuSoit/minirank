# MiniRank

A keyword position tracker. All ranking data is simulated locally — no search engines or external APIs involved. Positions are numbers 1–100 where **lower is better** (rank 1 is the top result, 100 is the worst).

The app requires a login (a demo account is seeded — see below). Keywords are organized into **projects**, each tracking a different website.

## What it does

- **Keyword list** — see every tracked keyword in a project, its current position, a 7-day trend indicator (improved / declined / stable), and search by phrase.
- **Projects** — group keywords by tracked website. Switch projects via the header dropdown. Add / edit / delete projects.
- **Add / Edit / Delete** keywords through simple HTML forms.
- **Refresh positions** — generates a new simulated position for today for every keyword in a project via AJAX, without a page reload.
- **Keyword detail** — per-keyword page with the full position history as a table and a line chart.

## Tech stack

- **PHP 8**, plain PHP with PDO — no framework.
- **SQLite** via `PDO_SQLite`, stored as `data/minirank.sqlite` (git-ignored, regenerated by the seed script).
- **Vanilla JS** for the AJAX refresh, hand-written CSS for layout (mobile-responsive).

## Requirements

- PHP 8.1+
- The `pdo_sqlite` PHP extension (included in most PHP installations).
- Composer (for running tests)

## Setup

```bash
# 1. Seed the database (creates schema + 30 days of demo data)
php seed.php

# 2. Start the built-in server
php -S localhost:8000 -t public public/router.php

# 3. Open in your browser
open http://localhost:8000
```

That's it — the app is running. To start fresh at any time, re-run `php seed.php` (it deletes and recreates the database).

### Docker

```bash
docker compose up            # first run builds the image
# then open http://localhost:8000
```

To regenerate the demo database from inside the container (**CLI**, not an HTTP request):

```bash
docker compose run --rm web php seed.php
```

### Testing

```bash
curl -sS https://getcomposer.org/installer | php      # download composer
php composer.phar install        # install PHPUnit
vendor/bin/phpunit      # run the test suite
```

Tests cover input validation (`validateIntId`, `validateString`), trend calculation (`calculateTrend`, `getKeywordTrend`), the seed helpers (`clamp`, `generateWalk`), and HTML escaping.

The seed script creates one demo user with 2 projects (Shop, Blog), distributes 10 keywords across them, and generates 30 days of random-walk positions starting at a random base of 20–80. The refresh endpoint walks each position by ±3 per day, clamped to 1–100.

## Usage

| Action | How |
|---|---|
| Switch project | Use the **Project** dropdown in the header. |
| Add a project | Click the **+** next to the project dropdown, or go to `/project/add`. |
| Edit a project | Click **Edit project** on the keyword list page. |
| Delete a project | Click **Delete project** (cascade-deletes all keywords + positions). |
| Add a keyword | Click **Add keyword**, enter a phrase, submit. |
| Edit a keyword | Click **Edit** on a keyword row or on the detail page. |
| Delete a keyword | Click **Delete** (positions are cascade-deleted automatically). |
| Search | Type in the search box on the list page. |
| Refresh positions | Click **Refresh positions** on the list page — updates live via AJAX. |
| View history | Click a keyword's phrase to go to its detail page. |
 | CSV Export | On the keyword detail page, click **Export CSV** to download the full position history. |

## Resetting

```bash
php seed.php          # wipes data/ and regenerates the database
```
